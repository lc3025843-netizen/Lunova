# Lunova — registro de cambios

## v0.1 (en construcción)

La numeración no cambia mientras esta base no haya sido aprobada.

### Incluido en la base actual
- Identidad visual Lunova y favicon.
- Autenticación y perfiles.
- Supabase PostgreSQL con RLS.
- Storage privado para documentos Word.
- Documentos y revisiones persistentes.
- Guardado de borradores.
- Motor de reescritura por etapas.
- Protección de citas, referencias y cifras.
- Historial persistente.
- Panel de administración.
- Avisos por usuario.
- Configuración editorial, banner y mantenimiento sin redespliegue.
